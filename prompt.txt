## 4. Site-Wide Technical SEO & Indexing Overhaul

1. **Fix Google Indexing Blockers Immediately:**
   - Audit all layouts, `<head>` tags, `next.config` / headers, and meta tags for any accidental `noindex` or `nofollow` directives. Explicitly enforce `index, follow, max-image-preview:large, max-snippet:-1`.
   - Generate or fix `robots.txt` (`robots.ts`) to allow all crawlers and point to `https://casalallatakerkoust.com/sitemap.xml`.
   - Generate a dynamic, complete bilingual `sitemap.xml` (`sitemap.ts`) listing every valid FR and EN route with proper `xhtml:link` hreflang alternates and `lastmod` dates.

2. **Per-Page Bilingual Metadata & Canonical Architecture:**
   - Every single page in the project must have unique, keyword-optimized `<title>` and `<meta name="description">` tags in both FR and EN (targeting *Restaurant Lalla Takerkoust, Vue Lac Marrakech, Jet Ski & Quad Lalla Takerkoust, Day Pass Piscine, Événements Privés Marrakech*).
   - Every page must output strict self-referencing `<link rel="canonical">` tags and bidirectional `hreflang="fr"`, `hreflang="en"`, and `hreflang="x-default"` tags.
   - Include complete OpenGraph (`og:title`, `og:description`, `og:image`, `og:locale`, `og:url`) and Twitter Card tags for every route.

3. **Semantic HTML & Accessibility Across All Pages:**
   - Enforce strict heading hierarchy on every page: **exactly one `<h1>`** per page matching the page's primary intent, followed by logical `<h2>` and `<h3>` subheadings.
   - Add descriptive, localized (FR/EN) `alt` attributes to every `<img>` / `<Image>` across the entire project.
   - Ensure all interactive elements (buttons, language switchers, mobile drawers, booking links) have proper `aria-label` attributes.

4. **Site-Wide Structured Data (JSON-LD Schema):**
   - Implement rich JSON-LD structured data:
     - **Global / Homepage & Restaurant:** `Restaurant` and `LocalBusiness` schema (exact geo-coordinates for Lalla Takerkoust, unified `openingHoursSpecification`, priceRange, telephone, menu link, `sameAs` with the single TripAdvisor URL + Instagram).
     - **Activities / Experiences Page:** `TouristAttraction` or `OfferCatalog` schema for Jet Ski, Quad, Boat, and Day Pass packages.
     - **Inner Pages:** `BreadcrumbList` schema for clean search appearance in Google SERPs.
